## Project Objective
To analyze material flow and simulate procurement forecasting to improve service levels and reduce late deliveries. By identifying patterns within complex supply chain datasets, this project utilizes standard work principles and data-driven methodologies to optimize inventory turns and mitigate non-working inventory risk.

## Methodology: Lean Six Sigma (DMAIC)
This project follows the Lean Six Sigma DMAIC framework to ensure a structured, compliant approach to problem-solving and process improvement:

*   **Define:** Identify supply chain bottlenecks and establish the goal of reducing late delivery risk without introducing demographic or regional bias.
*   **Measure:** Establish baseline metrics for *Order Processing Time* and *Shipping Lead Time Variance* by cleaning and standardizing over 180,000 raw ERP records.
*   **Analyze:** (In Progress) Execute operational correlation analyses to identify the logistical root causes of delivery delays.
*   **Improve:** (Upcoming) Develop an interactive Power BI dashboard to visualize material flow and propose optimized Service Level Agreements (SLAs) for production schedules.
*   **Control:** (Upcoming) Implement Standard Operating Procedures (SOPs) and automated SQL procurement triggers to maintain continuous product flow.

## Technology
*   **Data Preparation & Feature Engineering:** Python (pandas,numpy) via Jupyter Notebooks
*   **Data Extraction & Logic Building:** SQL
*   **Visualization & Interactive Analysis:** Microsoft Power BI
*   **Methodology:** Lean Six Sigma, Standard Work
